# 🛒 TradeHaven

TradeHaven is a secure e-commerce platform UI that enables buyers and sellers to trade with confidence.  
The platform is built around a **buyer verification model**, where payments are only released after buyers confirm that the product received matches what was ordered.

> ⚠️ This repository contains the Angular frontend only.

## 🌍 About TradeHaven

Trust is one of the biggest challenges in online commerce. TradeHaven addresses this by designing a transparent transaction flow that prioritizes buyer confidence while protecting honest sellers.

This frontend application represents how users interact with the TradeHaven marketplace—from browsing products to confirming deliveries.

## 🔄 How the Platform Works (Concept)

1. 🛍️ Sellers list products  
2. 💳 Buyers place orders  
3. 🔒 Payments are held securely  
4. 📦 Products are delivered  
5. 📝 Buyers have **up to 7 days** to confirm the product matches the order  
6. ✅ Payment is released to the seller after confirmation
